Wykluczanie przebiegów

Dwie konfiguracje korzystają z tej samej tabeli apds_staging_line, a Etap 2 zaczyna od DELETE FROM apds_staging_line bez filtra. Przebiegi nie mogą się nakładać. _apds_start_delay_active wstrzymuje start Etapu 1, dopóki od write_date najnowszego logu APDS ze state = received nie minie apds_start_delay_minutes (konfiguracja startowanego logu). Brak takiego logu – brak ograniczenia.

Reguła nie obejmuje dwóch logów, które startują, gdy żaden przebieg nie był wcześniej zakończony, ani przebiegu, który trwa (stan w toku nie jest sprawdzany – tylko czas od ostatniego zakończenia).
