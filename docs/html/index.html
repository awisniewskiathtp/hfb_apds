Przegląd modułu

Provider APDS dla XET Base: synchronizacja produktów i kodów dostawców z plików JSON ALIAS.

Przeznaczenie

Moduł realizuje proces ALIAS Product Data Synchronization (APDS) jako provider XET Base (hfb_xmlmap_exporter). Jeden rekord communication.log to jeden przebieg: Etap 1 pobranie pliku JSON, Etap 2 strumieniowe przygotowanie stagingu PostgreSQL, Etap 3 równoległe przetwarzanie partii przez workery cron, finalizacja z raportem.

Od wersji 19.0.0.3.16 konfiguracja providera ma pole apds_import_type:

WartośćPlik źródłowyWynik w Odoo
productsplik główny (np. export_products_merged.json)product.template / product.product: tworzenie i aktualizacja, kategoria, tagi z flag, orderpointy
supplier_idsnowa struktura pliku ALIAS (np. export_products.json)product.supplierinfo (dostawca–kod produktu u dostawcy) oraz res.partner dla brakujących kodów dostawców; product.template bez zmian
